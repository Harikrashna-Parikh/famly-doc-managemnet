Setup Required

Welcome to the Family Digital Document Locker! To get started, you need to configure your Supabase project credentials.

1. Edit Supabase Config File

Open js/supabase.js in your editor.

2. Set Credentials

Replace the placeholders with your actual Supabase URL and Publishable (anon) API Key:

const SUPABASE_URL = "https://your-project.supabase.co";
const SUPABASE_PUBLISHABLE_KEY = "eyJhbGciOi...";

3. Deploy Tables & Policies

Copy and run the SQL queries in the supabase/ folder inside your Supabase SQL Editor.
